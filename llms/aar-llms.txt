# AAR Corp

> AAR CORP. (NYSE: AIR) is a global aerospace and defense aftermarket solutions company and
> the largest aviation maintenance, repair and overhaul (MRO) provider in North America. It
> supplies new and used aircraft and engine parts, performs airframe and component MRO,
> operates four aviation software businesses (Trax, Aerostrat, Airvoyant, Airinmar), and runs
> expeditionary and sustainment programs for government and defense customers.

## Developer status

AAR CORP. has no developer program. There is no developer portal, no API reference, no
machine-readable contract (no OpenAPI, AsyncAPI, GraphQL SDL or WSDL), no SDK on any package
registry, no sandbox, no changelog, no status page, and no security.txt on any host it
controls. Integration with AAR is sold through a commercial contract and is described only in
general terms: AAR states it uses "electronic data interchange (EDI) for transaction-level data
exchange and complete ERP system integration".

One live API surface exists and can be reached without credentials: the AAR PAARTS Store
commerce API. It is an Adobe Commerce (Magento 2) webapi mounted at
https://shop.aarcorp.com/rest/V1/. AAR publishes no documentation for it and the platform's own
schema endpoint (/rest/all/schema) returns HTTP 500, so no contract can be retrieved from it.

## Businesses

- [Parts Supply](https://www.aarcorp.com/en/parts/): New and used airframe and engine parts, rotables and used serviceable material, distributed to airlines, MROs and government customers.
- [Repair Services](https://www.aarcorp.com/en/repair/): Airframe MRO and component MRO, including avionics, landing gear and accessories.
- [Government Solutions](https://www.aarcorp.com/en/government-solutions/): Aircraft sustainment, mobility systems and expeditionary supply-chain programs for defense customers.
- [Software](https://www.aarcorp.com/en/software/): Four aviation software subsidiaries, covering more than 10,000 aircraft.

## Software products

- [Trax](https://www.trax.aero/): Cloud-hosted aviation ERP — eMRO maintenance management plus the eMobility mobile suite. Wholly owned by AAR since 2023.
- [Aerostrat](https://aerostratsoftware.com/): Aerros, an ERP-agnostic maintenance scheduling and aircraft allocation product. Acquired by AAR in 2025 and run under Trax.
- [Airvoyant](https://www.airvoyant.com/): AI-driven parts procurement platform launched April 2026, integrating with Trax and other ERPs and with the Aeroxchange supplier network. Marketed as an agentic AI workforce for airline and MRO procurement; no public API.
- [Airinmar](https://www.airinmar.com/): Component repair management and aircraft warranty support services, including the Airvolution repair-cycle workflow tool.

## Commerce

- [AAR PAARTS Store](https://shop.aarcorp.com/): Online aviation parts store.
- AAR PAARTS Store API base: https://shop.aarcorp.com/rest/V1 — Adobe Commerce webapi, undocumented by AAR. Anonymous reads at /rest/V1/directory/currency and /rest/V1/directory/countries; the catalog and store surfaces return HTTP 401.
